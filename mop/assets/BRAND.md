# Scruffy's Mop — brand assets

Same universe as Scruffy (`../../assets/scruffy-character.png`): flat 2D
adult-animation style, muted palette (deep green, warm gray, rust, ochre),
thick clean linework, no gradients, true-alpha PNG cutouts.

The Mop's emblem is the janitor seen from behind, mid-squeegee stroke on
invisible glass — the tool doesn't hide the mess, it makes the product
visible. The transparent "glass" means the mark cleans whatever background
it sits on. (Earlier mop-and-bucket direction retired 2026-08-14: keys and
bucket rendered poorly at emblem size.)

Files:
- `mop-hero.png` — 3:1 hero, character left, clear-glass space right.
- `mop-badge.png` — 1024×1024 square emblem for plugin icon / marketplace tile.
- `../../assets/scruffy-and-mop-hero.png` — combined banner: Scruffy sweeps
  the bolts toward the Mop janitor squeegeeing; audit → fix, one image.

Provenance: base art generated by Zach (imagegen pipeline, 2026-08-14,
back-view janitor with squeegee, transparent 3:1); composed/cropped
programmatically (PIL) in the Cowork session of the same date. No
third-party imagery.

Palette guardrails (binding, from the slop taxonomy): no purple/blue
gradients, no pastel AI palettes, one linework style, saturated color only
where it means something.
